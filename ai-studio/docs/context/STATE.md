## Implemented

- Narrative Sync + Scene Timing + Visual Polish v1 (no schema/migration): `GenerateAudio` now speaks the approved `ReviewedScript` (`title`/`openingHook`/`sections[]`/`closing`) instead of fabricated title+heading text. `ReviewedNarrationScript` parses the reviewed script and maps it to storyboard scenes deterministically (positional opening+sections+closing, else exact heading match, else structured `audio_narration_source_unmapped`). `NarrationText.Normalize` strips quote marks (VoxCPM2 emits degenerate near-zero-length audio for quoted spans) so speech and subtitles share one normalized source. Narration is generated per scene (`narration/scene_{i}.wav`, fingerprinted on text/voice/locale), assembled by the CPU `FfmpegNarrationAssembler` into `narration.wav` at speech-driven offsets; scene length is `introLead(0.25) + measured narration + outroHold(0.45)` with the 0.35s crossfade overlap, so assembled audio and rendered video share one timeline. Subtitles are derived phrase-by-phrase from the same narration inside each scene's speech window; choreography beats are scheduled inside the narration window; FLUX prompts forbid typography and a trusted SVG overlay supplies labels. `RenderVideo?variant=` yields a review artifact without overwriting canonical outputs. The AudioProduction manifest is v2 and records per-scene narration/timing.

- Visual Direction + Multi-Engine Choreography v1 (no schema/migration): deterministic `SceneVisualDirector` (intent from heading/visual) and `SceneVisualRouter` (preferred engine with documented availability fallback: ThreeD -> Manim -> AnimatedSvg; AiImage -> Manim -> AnimatedSvg; Manim -> AnimatedSvg), a curated `AnimationPrimitive`/`AnimationBeat`/`SceneChoreography` model + `ChoreographyEvaluator`, and a direction-driven `SceneVisualPlanner` (`PlannerVersion=3`). New `SceneVisualEngine.AnimatedSvg` renders a frame-sequence motion-graphics clip (`FfmpegSceneVisualRenderer.RenderAnimationAsync`); FLUX stills get a real motion treatment (`RenderImageMotionAsync`: slow push + animated overlay) instead of a static image. New trusted Manim `process_flow` template covers download/install and model-pull. `SceneAsset.Creator` now records `Engine+per-scene-fingerprint` for narrow per-scene reuse/invalidation; `GenerateSceneVisuals` gained an explicit `force` flag for intentional regeneration while manual assets are otherwise preserved. `RenderVideo` gained an optional `variant` query (e.g. `?variant=motion-v1`) so a review render never overwrites the canonical MP4. Blender seed clamped to Cycles' int32 range (root-cause fix).

- Production Orchestration v2 (no schema/migration): new durable `JobType.GenerateAudio` (`GenerateAudioWorkflow`, `GenerateAudioJobHandler`, `GenerateAudioJobPayload/Result`, new `POST /api/content-projects/{id}/storyboard-jobs/{storyboardJobId}/audio-jobs`). One job runs three internally staged steps — narration (VoxCPM2 Formal/id-ID, text derived deterministically from the storyboard title + scene headings), background music (ACE-Step instrumental, 90 BPM, seed 42, duration = ceil(narration)+2s clamped 5–120s) and the final mastered mix (`IAudioMixer`, 48 kHz stereo). Durable reuse: `AudioProductionWorkspace` stores artifacts at deterministic `audio/{projectId}/{storyboardJobId}/{narration,music,master}.wav` plus a small `manifest.json` of per-stage input fingerprints; each stage persists right after it completes, so a retry reuses every stage whose fingerprint, SHA-256 and probed media still match and regenerates only missing/invalidated stages. `RenderVideoResult` gained `audioSource`/`masteredAudioPath`/`masteredAudioContentHash` (narration track now optional); `RenderVideoJobHandler`/`RenderVideoWorkflow` prefer the validated master and fall back to the legacy narration track when absent. GPU semantics unchanged: providers own their `IGpuResourceGate` lease, orchestration holds none, the mixer stays CPU-only.

- Audio Generation v1 (providers only, no schema/migration, both engines disabled by default): new application boundaries `ISpeechSynthesisProvider` (`Application.Rendering.AudioGeneration`) and `IMusicGenerationProvider`. `VoxCpmSpeechSynthesisProvider` maps a small curated voice set (Formal/Playful/Energetic/Documentary) to approved Indonesian control text and launches the repository-owned `Rendering/VoxCPM2/synthesize.py` with a trusted model path plus one constrained JSON request (text, voice, timesteps, cfg, normalize, output). `AceStepMusicGenerationProvider` launches `Rendering/ACE-Step/generate.py` with a trusted project root/model plus one constrained JSON request (caption, duration, bpm, instrumental, seed, steps). Both persist the generated WAV through `IAssetFileStore`, verify it with `IMediaInspector` (audio present, duration > 0, expected sample rate; 2 channels and duration match for music), acquire the shared `IGpuResourceGate` for the process only and release before the CPU-only persist/probe, and map stable `speech_*` / `music_*` errors. Callers cannot supply python code, executable/model/project paths, CLI flags, or shell fragments. Config: `SpeechSynthesis:VoxCPM2:*` and `MusicGeneration:AceStep:*`; no `/home/tama` paths in source.

- Audio Mixing / Mastering v1 (no schema/migration): new standalone `IAudioMixer`/`FfmpegAudioMixer` (`Application.Rendering.AudioMixing` + `Infrastructure.Rendering.AudioMixing`). Narration + optional background music -> narration `loudnorm=I=-16:TP=-1.5:LRA=11`, music `loudnorm=I=-24:TP=-3:LRA=7`, sidechain ducking while narration is active, short music fade-in/out, `alimiter` at -1 dBFS, 48 kHz stereo `pcm_s16le` WAV bounded to the narration length (music looped when shorter, trimmed/faded when longer). Values centralized in `AudioMixingOptions`; no caller-supplied filter text. Inputs are approved asset references resolved through existing `IAssetFileStore`; output is a relative `.wav` under the approved root; execution reuses `IProcessRunner`/`IMediaInspector`. Structured `audio_*` errors. CPU-only: never acquires `IGpuResourceGate`; no shell; no arbitrary executable paths.
