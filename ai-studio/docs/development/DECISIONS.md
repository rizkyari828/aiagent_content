| D-029 | 2026-09-20 | Implemented | GPU Resource Gate v1 serializes heavy GPU workloads in-process behind a minimal `IGpuResourceGate` application boundary that returns an async-disposable lease. `GpuResourceGate` is a **singleton** `SemaphoreSlim(1,1)`, so all providers share one permit; callers cannot release manually, disposal is idempotent (`Interlocked`), release is deterministic via `await using`, and waiting honors cancellation without consuming the permit. `GpuResourceGate:Enabled=true` by default because it only serializes workloads and does not change functional results. Consumers: ComfyUI holds the lease across submit -> poll -> download (POST /prompt only queues, so releasing after submit would be incorrect); Blender holds it only across the CUDA PNG render and releases before the CPU-only FFmpeg encode; Ollama is integrated because its `IAiTextGenerator` boundary was already clean and localized (no broad refactor). Observability is structured `ILogger` events (workload, wait duration, acquire/release) with no prompt/content logging. Deliberately excluded: priorities, fairness, VRAM estimation, GPU polling, multi-GPU routing, cross-process/Redis locks, preemption, and model lifecycle management. The gate is process-local and does not coordinate other AI Studio processes, manually launched ComfyUI/Blender jobs, external Ollama clients, or Windows GPU work. No schema/migration. |
