- Basic FFmpeg Composition: DONE. New durable `JobType.RenderVideo` produces one playable MP4 at deterministic `renders/{contentProjectId}/{storyboardJobId}.mp4` under the approved `Assets:RootPath`; no new table/schema (render evidence lives in `Job.Result`: output path, SHA-256, byte size, probe duration, dimensions, storyboard job, narration track, scene count, narration hash). Enqueue and handler both gate on project, a completed `GenerateStoryboard` result, one asset per scene bound to that storyboard, and that storyboard's narration. Handler re-reads every input through `IAssetFileStore` and rejects any file whose SHA-256 no longer matches its recorded hash. External process execution sits behind the single `IProcessRunner` boundary (`SystemProcessRunner` uses `ProcessStartInfo.ArgumentList`, no shell, bounded by `Rendering:TimeoutSeconds`; `FfmpegVideoRenderer` maps start failure/timeout and validates args). The renderer writes to a temp file, probes the result with `ffprobe` (video + audio stream, duration > 0), then atomically promotes it. Composition is minimal: scale/pad to `Rendering:Width`x`Height`, `fps`, one image/video input per scene, `concat`, `libx264` + `aac`, `+faststart`.
- Basic Subtitles: DONE. The v0.9.2 NOW/Video #1 path includes Subtitle, so an optional operator-provided `.srt` is supported. One `subtitle_tracks` row per ContentProject (additive migration `20260918081522_AddSubtitleTracks`) stores only metadata (source storyboard job, relative path, byte size, SHA-256, origin, source/creator/license/retrievedAt, createdAt), never bytes. Registration mirrors narration: project + completed GenerateStoryboard gate, `.srt`-only, external provenance, duplicate/format/missing-file/root-escape rejection, reusing `IAssetFileStore`. Rendering embeds the matching track as soft subtitles (`-i` input + `-map N:s:0` + `-c:s mov_text`) when its `SourceJobId` matches the render storyboard; a missing or mismatched subtitle is ignored, a tampered one is rejected before render. `Job.Result` records `subtitleTrackId`/`subtitleContentHash` when present.
- Basic Render Timing: equal scene duration = narration duration / scene count (marked with a `ponytail:` comment in `FfmpegCommandPlan`). No per-scene alignment or transition system was added.
- Final Video QA: DONE. New durable `JobType.FinalVideoQa` validates a completed `RenderVideo` `Job.Result` against its promoted MP4 with no new table/schema. The handler re-reads the artifact through `IAssetFileStore` (path safety, non-empty, SHA-256) and rejects a stored hash mismatch, then probes with the shared `IMediaInspector`/`FfprobeMediaInspector` process boundary (the renderer now reuses it instead of duplicating ffprobe parsing). It enforces duration > 0, video stream, audio stream, positive dimensions, and the expected subtitle stream when the render result recorded one. Result is an immutable `FinalVideoQaResult` `Job.Result` (output path, content hash, duration, dimensions, stream presence); failures throw stable `qa_*` `JobExecutionException` codes (`qa_artifact_missing`, `qa_hash_mismatch`, `qa_probe_failed`, `qa_duration_invalid`, `qa_video_stream_missing`, `qa_audio_stream_missing`, `qa_subtitle_stream_missing`, plus gating codes). Deterministic checks only; no AI/quality scoring. Enqueue is `POST /api/content-projects/{contentProjectId}/render-jobs/{renderJobId}/qa-jobs`. `PlaceholderJobHandler` now excludes `RenderVideo`/`FinalVideoQa`, fixing a latent `SingleOrDefault` dispatch overlap.
- Video Quality v1: DONE. The existing `FfmpegCommandPlan`/`FfmpegVideoRenderer` boundary gained deterministic scene motion (`zoompan`; `none`/`slow_zoom_in`/`slow_zoom_out`/`pan_left`/`pan_right`), transitions (`cut` concat, `fade` per-scene, `crossfade` `xfade` with overlap-compensated scene duration), libass-styled burned-in subtitles (`subtitles` + `force_style`), and config-driven background music with `sidechaincompress` ducking and renderer-level per-scene SFX. No schema/migration: existing storyboards get motion/transitions from deterministic render defaults (`RenderingOptions.EnableMotion=true`, `Transition=Crossfade`), and `SceneMediaInput.Motion`/`SoundEffect` override them when supplied. Styled subtitles are burned in with no soft `mov_text` stream because FFmpeg's MP4 muxer forces a lone soft track to `default=1` (double-render risk); `RenderVideoResult.SubtitleBurnedIn` records it and `FinalVideoQa` requires a soft stream only when not burned in, with legacy results defaulting to `false`.
